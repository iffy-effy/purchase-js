# purchase-js — SAP 구매요청 자동화 Claude 스킬

"소포제 100kg, 고무이중코팅장갑 20개 구매팀으로 구매요청해줘" 한 문장으로 아래를 진행하는 Claude Code 스킬입니다.

1. 엑셀 PR자동화 파일에서 품목을 찾아 입력
2. SAP ME51N 구매요청 저장 → PR번호 확인
3. ME53N에서 Start Workflow 실행
4. 전자결재(joyNABI) 구매요청 작성 창을 크롬에서 열고, 제목과 개인결재선까지 입력
5. **[기안] 직전에서 멈춤**. 기안은 사람이 직접 누릅니다.

## 필요한 것

- Windows, Claude 데스크톱 앱(Claude Code)
- SAP GUI for Windows, **SAP GUI 스크립팅 허용**
- 크롬과 **Claude in Chrome 확장** (Claude 앱과 같은 계정으로 로그인)
- 엑셀 PR자동화 파일 `ME51N_현장소모품_PR자동화.xlsm`과 매크로 모듈(PR_ClearInput / PR_AddRow / PR_Run). **이 저장소에는 들어 있지 않습니다.** 팀 품목마스터가 들어 있는 파일이라 따로 받아야 합니다.
- 전자결재에 개인결재선 두 개 저장: `구매팀 구매`, `기술팀 구매`

## 설치

1. 이 저장소를 내려받습니다. 초록색 **Code → Download ZIP** 버튼을 누르거나, 아래 명령을 실행합니다.
   ```
   git clone https://github.com/iffy-effy/purchase-js.git
   ```
2. 폴더 이름을 `purchase-js`로 맞춰 `C:\Users\<내 계정>\.claude\skills\` 안에 넣습니다.
   결과: `C:\Users\<내 계정>\.claude\skills\purchase-js\SKILL.md`
3. 아래 "내 값으로 바꾸기"를 채웁니다.
4. Claude 앱을 다시 열고 `/purchase-js 품목 수량 구매팀 구매`처럼 쓰거나, 그냥 "OO 2개 구매팀으로 구매요청해줘"라고 말합니다.

## 내 값으로 바꾸기

`SKILL.md`에서 중괄호로 된 자리표시를 본인 값으로 바꿉니다.

| 자리표시 | 넣을 값 |
|---|---|
| `{엑셀 파일 경로}` | PR자동화 엑셀이 있는 폴더 |
| `{결재시스템 주소}`, `{로그온ID}`, `{회사}` | 전자결재 작성 창 주소의 호스트, 본인 로그온 ID |
| `{기안자}`, `{결재자1~3}` | 결재 순서대로 이름 (스킬이 결재선 적용 후 이 순서와 대조합니다) |
| `{참조…}` | 구매팀용·기술팀용 참조자 이름 (순서대로) |
| `{우리 팀}`, `{팀코드}`, `{코스트센터}`, `{G/L}` | 본인 팀 정보 (설명용) |

`scripts/sap_open.vbs` 위쪽 두 줄도 바꿉니다.

- `CONN_NAME`: SAP Logon에 보이는 접속 항목 이름
- `LNK_NAME`: (선택) 자동 로그인용 명령줄 바로가기 파일 이름. `%USERPROFILE%\SAP바로가기\` 안에 두면 SAP가 로그아웃되어 있을 때 스킬이 그 바로가기로 로그인합니다. 없으면 로그인 화면만 띄우고 사람이 로그인합니다.

## 주의

- 이 스킬은 **실제 SAP에 PR을 저장**합니다. 시험할 때는 기안하지 말고 PR 품목을 지우세요.
- SAP 보안 창에서 "Remember My Decision"은 체크하지 마세요. 체크하면 전자결재 연결이 실패한 적이 있습니다.
- SAP Start Workflow가 크롬에 띄운 작성 창과, 스킬이 연 작성 창이 따로 있습니다. **한쪽에서만 기안**하세요.
- 자동 로그인 바로가기에는 비밀번호가 그대로 들어갑니다. 그 파일은 본인 PC 로컬 폴더에만 두고, 회사 정책을 먼저 확인하세요.
- `.ps1` 파일은 UTF-8(BOM), `.vbs` 파일은 CP949로 저장되어 있습니다. 편집기에서 인코딩을 바꾸면 한글이 깨집니다.
